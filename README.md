# Rektor: Kampus Impian

Simulator manajemen universitas. Pemain berperan sebagai rektor yang membangun kampus dari nol hingga diakui dunia.

## Status
- 📄 Fase: *F0 — Fondasi*
- 🎯 Engine: Godot 4
- 📱 Target: PC + Web (Android menyusul)
- 🌐 Bahasa: Indonesia

## Struktur
- docs/gdd/ — Game Design Document
- docs/design/ — Core loop, ekonomi, wireframe
- game/ — Project Godot
- game/data/ — Semua angka balance (JSON, bukan hardcode)
